# App Shelf - App Store & Portfolio Workspace

Nền tảng App Store & Portfolio Workspace quản lý danh mục ứng dụng, đặc tả kỹ thuật SRS song ngữ (Việt - Anh), lộ trình phát triển (Backlog/Roadmap) và chia sẻ ứng dụng đa đối tượng.

## 🚀 Tính Năng Chính

- **Kho Ứng Dụng (App Store Workspace):** Trưng bày, phân loại danh mục, tìm kiếm và lọc ứng dụng theo công nghệ, trạng thái và mức độ ưu tiên.
- **Đặc Tả Kỹ Thuật (SRS Viewer & Editor):** Hệ thống đặc tả kỹ thuật chi tiết chuẩn kiến trúc song ngữ (Tiếng Việt & Tiếng Anh).
- **Lộ Trình Phát Triển (Backlog & Roadmap):** Quản lý tiến độ công việc, trạng thái các tính năng theo từng dự án.
- **Chia Sẻ Ứng Dụng (Multi-audience App Sharing):** Tạo liên kết chia sẻ danh mục ứng dụng phù hợp cho bạn bè, đồng nghiệp, đối tác hoặc giáo viên.
- **Bảo Mật & Phân Quyền (RBAC):** Xác thực Google OAuth 2.0 kết hợp Row Level Security (RLS) trên Supabase.

## 🛠️ Công Nghệ

- **Frontend:** React 19, TypeScript, Vite
- **Database & Auth:** Supabase PostgreSQL, Row Level Security (RLS)
- **Deployment:** Vercel

## 📦 Cài Đặt & Chạy Thử

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường development
npm run dev

# Kiểm tra tests
npm test

# Build production
npm run build
```
